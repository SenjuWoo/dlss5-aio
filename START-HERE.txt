DLSS 5 AIO

Download the current portable ZIP from:
https://github.com/SenjuWoo/dlss5-aio/releases/latest

Extract it, run DLSS5-AIO.exe, and press scan or add a game.
The runtimes page updates existing compatible NVIDIA/AMD/Intel DLLs.
Open a game to preview/install a compatible neural-rendering route.
Restore original or uninstall returns preserved files.

README.md explains support boundaries, logging and recovery.
The 2x faster NR model announced October 13 debuts October 16.
The old numbered component folders and root SHA256SUMS.txt refer to
legacy v1.4.8, which remains available for rollback.
